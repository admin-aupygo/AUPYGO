AUPYGO — Tables Events + RLS
==============================

Le script SQL complet et à jour est dans le fichier :

  SUPABASE_EVENTS_RLS.sql

Comment l’exécuter :
1. Ouvre Supabase → SQL Editor
2. Colle tout le contenu de SUPABASE_EVENTS_RLS.sql
3. Clique Run

Ce script est idempotent (peut être relancé sans danger).
Il crée / met à jour :
- events (avec is_paid, price, is_special_aupygo, reservation_confirmed)
- event_participants
- event_invitations
- toutes les policies RLS nécessaires
