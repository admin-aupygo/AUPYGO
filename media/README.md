# Médias AUPYGO (vidéos site)

Dépose ici les fichiers suivants (via l’interface GitHub : **Add file → Upload files**) :

| Fichier | Description | Taille indicative |
|---------|-------------|-------------------|
| `aupygo_welcome_web.mp4` | Welcome ~12 s (modal + bouton) | ~0,8 Mo |
| `aupygo_promo_web.mp4` | Promo complète ~1 min 30 | ~2,2 Mo |

Sans ces fichiers, les boutons vidéo s’affichent mais la lecture échouera jusqu’à l’upload.

Les versions optimisées web sont générées en 720p H.264 pour un chargement rapide sur mobile.
