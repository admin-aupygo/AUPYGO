AUPYGO — Comment mettre à jour le site (structure sectorisée)
==============================================================

1) Télécharge le fichier AUPYGO-sectorized.zip (fourni par Grok dans le chat)

2) Dézippe-le sur ton ordinateur

3) Ouvre ce lien :
   https://github.com/admin-aupygo/AUPYGO/upload/main

4) Glisse dans la page :
   - index.html
   - le dossier css
   - le dossier js

5) Clique le bouton vert "Commit changes"

6) Attends 1-2 minutes puis regarde ton site

C'est tout. Rien d'autre à faire.

Les anciens fichiers à la racine (styles.css, app.js, config.js, i18n.js…)
ne sont plus utilisés et peuvent être supprimés plus tard si tu veux.
